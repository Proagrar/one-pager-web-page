# Slike

Postavite vaš logotip tukaj:

## Priporočene slike

1. **Proagrar_LOGO-17.svg** - Logotip podjetja (SVG format, priporočena širina 180px)
2. Druge slike za storitve, študije primerov, itd.

## Optimizacija slik

- Uporabite SVG za logotipe in ikone
- Optimizirajte fotografije pred nalaganjem
- Uporabite WebP format za boljšo kompresijo
- Dodajte `loading="lazy"` atribut za slike pod pregibom

## Orodja

- [SVGOMG](https://jakearchibald.github.io/svgomg/) - SVG optimizacija
- [TinyPNG](https://tinypng.com/) - Kompresija slik
- [Squoosh](https://squoosh.app/) - Optimizacija slik
